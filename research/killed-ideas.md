# Killed ideas

This file records ideas rejected by evidence so the project does not repeatedly revisit them.

| Idea | Status | Reason | Evidence |
|---|---|---|---|
| Full AI Workforce OS from day one | Rejected | Too broad before a painful wedge is proven | Product strategy decision |
| Generic chatbot | Rejected | Crowded and weak differentiation | Initial thesis review |
| Generic agent framework | Rejected | Large existing ecosystem | Initial thesis review |
| Agent marketplace alone | Open / weak | Major vendors already operate marketplaces | Requires further research |
| Agent identity/security control plane | Open / crowded | Strong incumbent activity | Requires customer research |
| Agent FinOps as standalone company | Open / crowded | Existing cloud/FinOps activity | Requires differentiation |
