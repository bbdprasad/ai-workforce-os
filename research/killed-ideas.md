# Killed ideas

This file records ideas rejected by evidence so the project does not repeatedly revisit them.

| Idea | Status | Reason | Evidence |
|---|---|---|---|
| Full AI Workforce OS from day one | Rejected | Too broad before a painful wedge is proven | Product strategy decision |
| Generic chatbot | Rejected | Crowded and weak differentiation | Initial thesis review |
| Generic agent framework | Rejected | Large existing ecosystem | Initial thesis review |
| Agent marketplace alone | Open / weak | Major vendors already operate marketplaces | Requires further research |
| Agent identity/security control plane | Open / crowded | Okta, CyberArk, SailPoint, and PlainID all shipped agent-identity features or GA products in H1 2026; Gartner named agent IAM a 2026 CISO priority | `research/competitors.md`, Sept 2026 scan |
| Agent FinOps as standalone company | Open / crowded, but younger | Cloud FinOps incumbents (Finout, AWS) extending downward, model/platform vendors (Anthropic, Snowflake) extending native attribution upward, several seed-stage entrants (Revenium, Carrot Labs) in between | `research/competitors.md`, Sept 2026 scan |
| Generic agent evaluation/observability platform | Open / crowded | LangSmith, Arize, Langfuse, Galileo, Braintrust, Maxim AI, Patronus AI, Humanloop all compete here; comparison content is now its own genre, a sign of category maturity | `research/competitors.md`, Sept 2026 scan |
