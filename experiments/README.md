# Experiments

The project advances through small, falsifiable experiments.

## Experiment template

### Objective
What uncertainty are we trying to reduce?

### Hypothesis
A specific statement that could be proven wrong.

### Method
What will we do?

### Evidence
What observations count as evidence?

### Decision rule
What result means pursue, modify, or kill?

### Result
Record observations, links, data, and quotes where appropriate.

### Decision
**Pursue / Modify / Kill / Retest**

## Phase 0 priority

The first experiments should be customer and market validation, not application development. Use `research/customer-discovery.md` for the interview guide and `research/hypotheses.md` for the claims each experiment should produce evidence against.
