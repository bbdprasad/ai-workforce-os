# MVP discovery

No MVP has been selected yet.

## Selection criteria

The first wedge should score strongly on:

- painful and frequent problem;
- identifiable economic buyer;
- measurable ROI;
- urgent because of agent adoption;
- technically feasible for a small team;
- low initial infrastructure cost;
- difficult for incumbents to solve completely;
- natural expansion path into the broader AI Workforce OS.

## Candidate wedges

1. Agent workforce inventory and ownership
2. Agent reliability / evaluation
3. Agent simulation before production
4. Agent economics and value attribution
5. Agent identity / permissions
6. Agent procurement / lifecycle management

The ranking must be evidence-driven rather than preference-driven.

## Current signal

`research/competitors.md` (Sept 2026 scan) shows candidates 4 and 5 above (agent economics, agent identity/permissions) already have crowded, well-funded incumbent activity, and candidate 2 (evaluation) overlaps heavily with an established observability/eval market. Candidate 3, pre-deployment simulation, is the least crowded of the group so far and is flagged as the priority for further customer discovery in `research/competitors.md`. This is a signal, not a decision: it still needs interview evidence via `research/customer-discovery.md` before ranking changes.

Once a wedge is selected, see `docs/moat.md` and `docs/business-model.md` for the open defensibility and pricing questions that follow from it.
