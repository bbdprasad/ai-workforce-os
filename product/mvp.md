# MVP discovery

No MVP has been selected yet.

## Selection criteria

The first wedge should score strongly on:

- painful and frequent problem;
- identifiable economic buyer;
- measurable ROI;
- urgent because of agent adoption;
- technically feasible for a small team;
- low initial infrastructure cost;
- difficult for incumbents to solve completely;
- natural expansion path into the broader AI Workforce OS.

## Candidate wedges

1. Agent workforce inventory and ownership
2. Agent reliability / evaluation
3. Agent simulation before production
4. Agent economics and value attribution
5. Agent identity / permissions
6. Agent procurement / lifecycle management

The ranking must be evidence-driven rather than preference-driven.
